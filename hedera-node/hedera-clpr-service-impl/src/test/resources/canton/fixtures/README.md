## Not extracted

The reference repo builds its happy-path bundles (verdict, opening, mediator set, anchor, payload) at test
time from synthetic keys; there is no single hex-constant bundle. Later tasks derive
verdict/opening/mediator-set/anchor inputs from the real material above (the JSON bundle carries the full
real transaction views) or build synthetic ones in Java. The Ed25519/P-256 key and signature arrays in
are synthetic and not extracted.
